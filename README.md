## 🛠️ Usage

### First Launch

When you open OpenShot for the first time, you’ll see a clean, three‑panel layout:

- **Left panel:** Your media files (import videos, images, audio).
- **Center:** The preview window.
- **Bottom:** The timeline where you arrange clips.

### Quick Start: 4 Steps to First Edit

1. **Add your media** – Drag videos/photos/music from your desktop into the left panel, or click the **“+”** button.
2. **Drag clips onto the timeline** – Click a file and pull it down to the track area. Repeat for other clips.
3. **Trim & arrange** – Click the edge of any clip and drag to trim. Move clips left/right to reorder them.
4. **Export your video** – Click the orange **“Export”** button (looks like a film strip). Choose a format (MP4 is best), pick a folder, and press **“Export Video.”** Done!

### Handy Tips

- **Add text:** Click **“Titles”** menu → choose a template → type your text.
- **Add music:** Drag an MP3 file onto a separate audio track.
- **Undo any mistake** with `Ctrl+Z`.

## ⚠️ Troubleshooting

Here are common issues and how to fix them:

- **“Windows protected your PC” warning** → Click **“More info”** → **“Run anyway”**. This happens because the file is unsigned, but it’s safe.
- **App doesn’t open when double‑clicked** → Ensure the ZIP was fully extracted (right‑click → “Extract all”). Try running it as administrator (right‑click → “Run as administrator”).
- **Black screen in preview** → Close other heavy programs (like Chrome) to free up memory. Also make sure your display drivers are up to date.
- **No sound in export** → In the export window, check that “Audio” is set to **“AAC”** under the **“Profile”** menu.
- **The interface looks blurry** – Right‑click the `.exe` file → **Properties** → **Compatibility** → check **“Disable display scaling on high DPI settings.”**

If the issue persists, see the Support section below.
